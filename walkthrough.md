## 2. PostgreSQL Production Persistence Hardening

Updated [`src/civilization/persistence/postgres-adapter.ts`](file:///d:/Downloads/Flop%20Website/src/civilization/persistence/postgres-adapter.ts), [`src/civilization/persistence/migrations.ts`](file:///d:/Downloads/Flop%20Website/src/civilization/persistence/migrations.ts), and [`src/civilization/gateway/server.ts`](file:///d:/Downloads/Flop%20Website/src/civilization/gateway/server.ts):
- **Dynamic Query Parameter Translation**: `translatePostgresParams` automatically converts standard `?` parameter placeholders to PostgreSQL `$1, $2, ...` positional parameters while preserving string literals.
- **Dialect-Aware Migrations**: Automatically applies `POSTGRES_INITIAL_MIGRATION_SQL` (`sequence_num BIGSERIAL PRIMARY KEY`) or `SQLITE_INITIAL_MIGRATION_SQL` (`sequence_num INTEGER PRIMARY KEY AUTOINCREMENT`) based on the detected database adapter.
- **Server Singleton Gate**: `getServerEventStore()` and `getServerIngestionGateway()` automatically validate production startup configuration before creating stores.

## 3. API Routes & Adversarial Security Hardening

Updated [`app/api/civilization/events/route.ts`](file:///d:/Downloads/Flop%20Website/app/api/civilization/events/route.ts) and [`app/api/civilization/events/stream/route.ts`](file:///d:/Downloads/Flop%20Website/app/api/civilization/events/stream/route.ts):

- **Comprehensive Adversarial Security Test Suite**: Created and passed [`tests/civilization/production_security_adversarial.test.ts`](file:///d:/Downloads/Flop%20Website/tests/civilization/production_security_adversarial.test.ts) testing forged signatures, replay attacks, mismatched DIDs, oversized payloads, excessive clock drift, and unauthorized escrow/judicial operations.

## 5. Legacy WSL/Linux Identity Backward Compatibility

Created [`src/identity/legacy.ts`](file:///d:/Downloads/Flop%20Website/src/identity/legacy.ts), [`tests/identity/legacy_migration.test.ts`](file:///d:/Downloads/Flop%20Website/tests/identity/legacy_migration.test.ts), and [`tests/audit/legacy_backward_compatibility_audit.test.ts`](file:///d:/Downloads/Flop%20Website/tests/audit/legacy_backward_compatibility_audit.test.ts):
- **Exact Legacy Format**: Unmodified `agent_key.json` files generated by `flop_agent.py` are parsed and validated 100% client-side in the browser.
- **Identity & DID Continuity**: Mathematically proven $\text{Legacy DID } \equiv \text{Migrated Session DID } \equiv \text{Restored DID } \equiv \text{Event Author DID}$.
- **Cumulative Citizen State**: Existing historical events signed via the CLI and new events signed via the web interface resolve to the exact same citizen record without duplicate entity creation.
- **Passphrase Hardening**: Converts legacy unencrypted keys into `technocore-agent-backup-v1` format using PBKDF2 (600,000 iterations) + AES-256-GCM, auto-downloads the backup, and immediately wipes raw key material from memory.
- **Dual-Tab UI**: Implemented in [`src/ui/import/ImportPanel.tsx`](file:///d:/Downloads/Flop%20Website/src/ui/import/ImportPanel.tsx) with explicit warnings to delete/secure the unencrypted legacy JSON file.
